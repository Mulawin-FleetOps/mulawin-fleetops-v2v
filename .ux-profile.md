# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** "Mission control" — fresh, bold, creative, futuristic through precision, not effects. Crisp 1px borders, high contrast, dark-capable surfaces. Existing green (#14652f / #18783a) is the single signal colour; --brand-red reserved for alerts and overdue maintenance. Bold type scale with tabular/monospaced numerals for trips, fuel, and accounting figures. Map-first routing views. Motion is fast and purposeful (live status pulses, number tick-ups); command-palette feel.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** > 4.5:1 normal text; 3:1 large text and borders
- **Touch / focus:** 44×44px targets on touch viewports (current 36px --fu-control-height must grow there); refined visible focus rings

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Cold, precise, invisible. Short, exact copy for dispatchers, drivers, and accountants.

## Icon library

- **Library:** Bootstrap Icons
- **Package / path:** public/assets/vendor/bootstrap-icons (loaded in public/index.php)
- **Notes:** Single set for product UI; no mixing sets; no emoji as UI icons.

## Precedence

`AGENTS.md` takes precedence over this profile. When fixing a functional bug, do not redesign: preserve the yellow active-menu indicator, pastel summary icons and operational status badges. The "Mission control" direction applies to new or explicitly requested UI work only.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
